# Password Generator 🔐

A simple Python-based password generator that creates strong, random passwords to enhance your online security.

## 📌 Features
- Generates secure passwords of customizable length.
- Supports a mix of uppercase letters, lowercase letters, numbers, and special characters.
- Lightweight and easy to run — no extra dependencies required.
- User-friendly command-line interface.
